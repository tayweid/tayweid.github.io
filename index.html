Knuth

Demo & install GitHub

A Python workbench for research, with a live session, a variable explorer, and results alongside the code. Analyses stay in plain Python files; named values and figures can flow into papers written in Plass.

Plass

Try the preview GitHub

A writing editor that typesets as you work. Write directly on the page with equations, citations, figures, and footnotes, then save as Typst or Markdown and export a PDF.
